# Agenda-12-DS

Para Utilizar o site baixe os arquivos e abra o visual studio code

O código começa informando ao navegador que estamos usando HTML5 e a linguagem da pagina usando os seguintes comandos 
<!DOCTYPE html>
<html lang="pt-BR">
.
Para poder usar a gramatica corretamente usei o seguinte comando <meta charset="UTF-8"> podendo utilizar acentos e caracteres especias.
.
h1 é o titulo principal já os h2 são "subtítulos" eu utilizei h2 para cada site
.
Para colocar as imagens eu utilizei os seguintes comandos <img>: adiciona uma imagem à página.
src: indica o endereço de onde a imagem será carregada.
alt="YouTube": fornece uma descrição da imagem, útil para acessibilidade e caso ela não carregue.
width="80": define a largura da imagem em 80 pixels.
.
Para poder abrir os sites eu utilizei os seguintes comandos.

<p>
    <a href="https://www.youtube.com">
        Acessar YouTube
    </a>
</p>
<p>: cria um parágrafo.
<a>: cria um link clicável.
href: define o endereço para onde o usuário será direcionado.
Acessar YouTube: é o texto visível do link.
</a>: encerra o link.

juntando as três partes da o resultado mostrado no código.
